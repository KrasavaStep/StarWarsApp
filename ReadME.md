## Реализация Splash Screen
### Переход и фон:
- Отключил дефолтный Splash Screen системы.
- Установил черный фон для окна (Window), что обеспечило бесшовный и плавный переход к кастомному экрану.
- Кастомная анимация (Canvas):
### Реализовал динамический звездный фон в стилистике приложения.
- Звезды отрисовываются через Canvas как белые круги.
- Для создания эффекта глубины и мерцания использован рандомный параметр alpha для каждой частицы.
### Эффекты появления:
- Настроил плавный анимированный выход (Fade-in/Slide) главного заголовка приложения.
